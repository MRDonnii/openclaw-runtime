# Domain Adapters

Denne mappe er reserveret til domænespecifikke adaptere ovenpå den fælles OpenClaw-runtime.

## Første adapter
- `heating`

## Næste sandsynlige adapter
- `tesla`

## Mål

Hver adapter bør beskrive:
- hvilket payload der sendes ind
- hvilket resultat der forventes tilbage
- hvilke HA entities/services der opdateres
- hvilke routes eller callbackmønstre der bruges
